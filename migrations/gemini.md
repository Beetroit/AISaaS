# Migrations Component Overview

This directory manages database schema changes for the AgentSync Pro application using Alembic. It provides a version control system for the database, allowing for incremental updates and rollbacks of the PostgreSQL schema.

## Key Files and Directories:

*   `alembic.ini`: The main configuration file for Alembic, specifying the location of migration scripts, Python path settings, and logging configuration.
*   `env.py`: The environment script executed by Alembic. It configures the database connection using the application's settings (`backend.app.config.settings.database_url`), imports all SQLAlchemy models to define the `target_metadata`, and sets up the asynchronous migration context.
*   `versions/`: This directory contains individual migration script files. Each file represents a specific database schema change, generated by Alembic (e.g., `066a23b42fe7_added_chat_history_and_agent_persona.py`). These scripts define `upgrade()` and `downgrade()` functions to apply and revert schema modifications.

## Dependencies:

*   **Alembic:** The database migration tool.
*   **SQLAlchemy:** The ORM used by the backend, whose `Base.metadata` is used by Alembic to detect schema changes.
*   **PostgreSQL:** The target database for schema migrations.

## Interactions:

*   **PostgreSQL Database:** Directly interacts with the PostgreSQL database to apply schema changes (creating tables, altering columns, etc.) during migration operations.
*   **Backend Application (`backend.app.config` and `backend.app.database`):** Relies on the backend's configuration for the database URL and its SQLAlchemy `Base.metadata` for defining the current state of the database schema.

## Important Notes:

*   **Asynchronous Operations:** Configured to handle asynchronous database connections, aligning with the FastAPI backend.
*   **Schema Version Control:** Ensures that database schema changes are tracked and applied in a controlled manner.
*   **Autogeneration:** Migration scripts can be automatically generated by Alembic based on changes detected in the SQLAlchemy models.
*   **Manual Review:** Generated migration scripts should always be reviewed manually before applying them to a production database.
